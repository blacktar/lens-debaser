# Projection Test — Resolve checklist

Use Lens Debaser Projection Test, not the released 1.69 node. Load 00-Neutral-reference.ldbpreset with the plug-in Load button; the remaining presets in that folder should appear in the Preset menu. These are test states, not creative factory recommendations. Loading each file starts from neutral defaults.

1. Neutral and disabled behavior — compare 00 with 01, 02 and 03 on the same clip. All four should look identical. Compare 00 with a clean released 1.69 node too. With 11 loaded, change Amount to 0, then separately Angle to 0 with Amount restored: both should preserve the optical treatment in 11.
2. Model and framing — compare 04/05 for model character; compare 04/06/07 for framing. Only projection geometry should change. Use architecture for straight lines, faces for proportions, and fine detail at native timeline resolution. Existing six creative examples cover Amount 20/45/70%; also drag Amount continuously and try Angle 1°.
3. Limits and displaced centre — 08/09 exercise 89° and 100% Amount; 10 moves the optical centre. Strong magnification, stretched edges and lost framing can be expected at extremes. Look for corruption, flashing, sudden discontinuities, hangs or crashes. Move the centre manually toward corners with projection active.
4. Existing optics — compare 11/12, which share distortion, chromatic aberration and vignette. Projection should coexist with these effects. In 12, switch Model to Off: it should match 11. Also load a familiar existing 1.69 preset: projection should default Off and retain the prior look.
5. Preset state — load 04; change Amount 45 → 46 and confirm the asterisk appears; restore 45 and confirm it clears. Repeat for model, angle and framing. Save a custom preset, load another, reload the saved file, and check every value. Save/reopen the Resolve project and confirm values survive. Clean Slate should return projection to Off, Amount 0, Angle 55 and Balanced framing.
6. Motion and host views — play a short moving clip with 04/05 and 12. Check stable geometry, full-resolution viewer, playback, thumbnails and a short export. Compare still/paused frames with export. Check landscape and portrait clips; judge sharpness at native source/timeline resolution, without proxy or reduced playback resolution. Record any thumbnail scaling issue separately from the full-resolution result.

Start with checks 1, 2 and 5; then stress limits and playback. Report failures by preset number, clip/timeline resolution, viewer or export, and reproduction steps. Automated GPU tests already passed; this checklist covers host behavior and visual judgement. No benchmark or new render sweep is required.
